# 上游 v2.2.4 的 iPhone 移植

比较范围：上次移植的 `upstream-v2.1.0`（1e0e793）到 `v2.2.4`（fae8c68）。
来源：https://github.com/jhaizhou-ops/d2r-mobile/releases/tag/v2.2.4
仅针对当前 iPhone / iOS 26+ 分支；未覆盖本地代码树。

## 本次变化

- 选项 → 自定义新增「允许竖屏（局内转屏）」。默认开启以保持现状；点「应用」才生效并写入 `sw_custom.txt` 的 `allow_portrait`。关闭后请求横屏，前后台恢复仍遵守此设置。「放弃」不改变当前值，「默认」待应用后恢复开启。
- 开启后沿用初始横屏策略，重新采样姿态基线，需再次转动手机才进入竖屏，避免恢复旧姿态造成意外跳转。
- 任务日志：首次点选显示当前目标，再次点击可回放对话；空白处不会清空目标。
- 战争召唤等副手装备技能换手后继续显示；自动增益连续失败后冷却重试，移动、受击或死亡不计入这轮失败。
- 储藏箱/魔盒临时偏移不写入原生物品栏原点；框体消失时清理偏移，保留既有原位保护。编年史标签扩大命中区域，空图标可重试。
- 小地图增加出口目的地、传送点名称，名牌避让，站在入口附近隐藏重复名牌。保留本地竖屏坐标换算。生成名牌时复用已确认的简中词条修改，更新旧译名图片避免缓存残留。
- 全屏地图点击空地不再退出；局外地图开关保护已在本地实现，继续使用带 HUD / AutoMap 检查的本地版本。
- 暗处亮度三档：原版、适度加亮、加亮；默认沿用原有加亮强度。
- 阿卡拉免费重复洗点，同步服务端与客户端任务状态；属于上游新增的玩法变化。
- 客体线程退出先返回宿主栈；崩溃先写无分配器依赖的基本记录，再对可阻塞的详细导出设置 3 秒退出期限。

## 保留与筛选

保留原字体、MetalFX、独立横竖屏镜头、竖屏 HUD、掉落标签插值和 39 条待发布的简中编辑。
未引入 Android/HarmonyOS、Mac 界面、旧 iOS 分支或实体手柄配置。v2.2.4 的手柄自定义页自动滚动路径在本 iPhone 触屏版本移除，未增加手柄状态扫描。

未移植 Android 风格镜头及其超前绘制整套改动：上游占用 `0x8f`，本地该编号用于掉落标签绘制，且涉及整套投影与镜头行为；本次保持已验证的 iPhone 镜头。未引入手柄提示条的新增 `0x90` 二进制门。本次没有改写客体门编号。

## 验证与限制

本地 21 项既有横竖屏、触控、地图、HUD、MetalFX 回归通过。
新增允许竖屏/亮度的默认、待定、应用、放弃、持久化重读、重置和非法配置测试通过；镜头设置独立性通过。
上游储藏箱回归 203 项、图标缓存回归 672 项通过；自定义布局、编年史标签命中与文字边界、中英资源校验通过。
可在 Apple ARM64 开发机执行 `make -C dm/host/tests ios224-regression`，包含崩溃导出阻塞测试。

当前 Windows 环境没有 Apple SDK；本次没有编译 IPA、执行 iPhone 真机验证或发布。线程退出与崩溃信号处理需 Apple 平台验证。下次出包必须重生成覆盖层和 mapgoal 图片；旧地图图片目录不包含新增出口名牌。
