# 上游 v2.1.0 移植记录

上游发布：`jhaizhou-ops/d2r-mobile`，标签 `v2.1.0`，源码 `1e0e7934c9ccdf95494aee5065d1d07ab3cc3918`。本分支基于自己的 iPhone 版更新，没有直接覆盖整棵源码树。

- 移植实验性镜头：自定义页可选原版、越肩和第一人称，默认原版。包含镜头矩阵、触摸拖动、移动/瞄准换算、名字与命中投影、怪物与地图朝向指示。
- 移植剧情跨幕后地图恢复：过场播放期间不触发地图键，恢复局内后仅在「进局自动开启地图」启用时按现有有界重试策略恢复。手动关闭仍受原有场景策略保护。
- 移植加宽储藏箱关闭后物品栏反复偏移的上游修复，限定于 `MV_WIDE`，避免改变竖屏 HUD 的坐标恢复规则。
- 保留已有竖屏与横屏独立缩放、MetalFX、原有字体、自定义页性能模式、光柱常开以及触控映射。上游 Android、HarmonyOS、实体手柄和低版本 iOS 专属更新未引入。

镜头指示图标由 `dm/ios/tools/gen_map_goal_art.py` 从原游戏素材生成。旧版构建输入需按源码重新生成图标资源与覆盖层，不能只复用旧的已生成 `mapgoal` 目录。该生成器已用本机准备包验证了 `heading.png` 与四种 `threat_*.png`。

验证包括相机矩阵单测、相机档位及设置读写测试、触摸视角手势、地图策略、储藏箱位置还原、竖屏 HUD、双方向缩放、转屏、MetalFX、菜单布局和素材生成。本次未使用 Apple SDK 编译，也未在 iPhone 真机验证；镜头属于上游实验功能，需要实机检查触摸、投影、场景遮挡与竖屏适配。旧问题：文字阴影偏移、小地图实际绘制位置以及选项焦点越界仍需单独处理。
